About DOM mode

FloeBrowser rebuilds the source page’s DOM here. Website scripts, requests and actions stay in the source browser.

Source tabs and embedded frames run on the source machine. Video and audio are forwarded from source media elements. Protected or origin-restricted media, canvas, file transfer and native browser dialogs are not supported. Unavailable content is marked in the page.

Reconnecting loads a fresh view. Unconfirmed actions are never automatically repeated.
